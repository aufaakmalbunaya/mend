mend is a command-line tool that applies AI-written edits in four formats (unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls) to a tree of text files, matching lines fuzzily and writing every change or none.

## Run it

```sh
node main.ts fix.patch
```
